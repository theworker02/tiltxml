# tiltxml

Tilt validation gates for xml inputs before they hit prod.

**Site:** https://theworker02.github.io/tiltxml/

## Install / run

```bash
git clone https://github.com/theworker02/tiltxml.git
cd tiltxml
node src/cli.js
node --test
```
